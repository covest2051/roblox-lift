# Плейтест «Лифта-сюрприза»: что проверить в Studio

60–80 минут. Порядок: запуск → лобби и кабина → каждый этаж (DBG → «◀▶ этаж» → «▶ floor») → балкон → крыша и падение → телефон → вдвоём → магазин → отладка. На заглушке движка нельзя проверить физику людей, свет, камеру, звук, вид частиц и ощущение — это здесь.

## 0. Запуск (3 мин)
```powershell
git pull
rokit install
rojo build -o game.rbxl
```
Открой `game.rbxl`, **View → Output**, **Play**.
- [ ] Ты в холле: ковёр, диванчики, вывеска «ЛИФТ-СЮРПРИЗ», латунные двери лифта открыты. В Output нет красных строк, есть `[World] ready`.
- [ ] Через ~6 с: `[SELFTEST] RESULT 9/9 passed`. Ожидаемый WARN: `products configured` (ID = 0) и, если не включён доступ к API, `player data saves`. FAIL — пришли строку.
- [ ] Сверху табло «🛗 L · Лифт отправляется через N», слева ⭐ 0 · 🪙 · 🏢 0/19, справа Коллекция и Магазин.

## 1. Кабина (5 мин)
- [ ] Через 20 с ты внутри бирюзовой кабины, рядом три бота-человечка (шар-тело, голова, примета: усы, кот, колпак…) с именами над головой.
- [ ] Играет тихая мелодия лифта; над дверью табло «1 ▲».
- [ ] Справа снизу — 3 большие кнопки с категориями «🔥 ? Выживание» и т. п., названия этажа нет. Нажал — на кнопке «1», обводка; на латунной панели в кабине тоже счёт.
- [ ] Иногда событие: мигает свет / трясёт / «Апчхи!» и конфетти.
- [ ] Двери открываются, звучит звонок, баннер «название + правило»; все стоят у двери на этаже, эффект выхода.

## 2. Этажи (по 2–3 мин каждый; DBG → этаж)
Для каждого: понятно ли без слов, что делать? Первые 3 с ничего опасного. Табло сверху объясняет происходящее.
| Этаж | Проверь |
|---|---|
| 🔥 Пол — лава | платформы тонут под ногами и краснеют, лава поднимается; упал в лаву — полёт на балкон |
| 🔥 Тающая плитка | плитка бледнеет и исчезает после шага; второй слой снизу; крыльцо у двери исчезает через 3 с |
| 🔥 Боулинг | наклонная дорожка, шары катятся сверху всё чаще; сбил — «СТРАЙК!» |
| 🔥 Цветная плитка | табло «ЦВЕТ: СИНИЙ!» и образец цвета; остальная плитка проваливается, потом новые цвета |
| 🔥 Гравитация пляшет | каждые 6 с «ЛУНА / ТЯЖЕЛО»; прыжок реально выше/ниже; остров краснеет и крошится, если стоять долго; звёзды собираются прыжком |
| 🏁 Зеркальный этаж | влево = вправо (только по сторонам); стеклянные мостики с разрывами; упал — на последний островок |
| 🏁 Пузыри | пузыри-батуты подбрасывают (клиент), покачиваются; кнопка на золотой площадке под потолком |
| 🏁 Каток | лёд скользит, синие трамплины подбрасывают, в полынью — обратно на край; монеты считаются |
| 🧠 Правда или ложь | утверждение на табло; зелёная/красная половины; неверная и серая середина проваливаются в поролон |
| 🧠 Библиотекарь | ходьба медленная («на цыпочках»); «Шуршит страница…» → она поворачивается; пошевелился — «Тсс!» |
| 🧠 Музыкальные стулья | музыка → стулья всплывают в случайных местах, кнопка «СЕСТЬ» (E) работает только рядом |
| 🤝 Тёмный этаж | свет гаснет, фонарик у всех; рубильник рядом — «НАЖАТЬ», издалека — «Подойди ближе»; гаснет через 14 с |
| 🤝 Торт на доставку | тележка едет, когда упираешься сзади; на жёлтом ухабе быстро — ярус падает |
| 🤝 Пингвины | убегают; коснулся — идёт за тобой гуськом (не больше 2); в вольере счётчик растёт |
| 😌 Курица-гигант | курица ходит по кругу, яйца прыгают, золотое — ×5 |
| 😌 Кафе | «ПОДАРОК» у стойки (ежедневный — раз в день), «ФОТО» в рамке — вспышка; манекены в шапках |
| 👑 Робот-пылесос | просыпается через 5 с, гонится всё быстрее; 3 выключателя почти разом — «Пылесос сломан!» |
| 👑 Мыльный пузырь | камни-ступеньки в шипах, батуты; подбиваешь головой — пузырь подскакивает; шипы — на балкон |
| ❓ Подвал | табло путает цифры, мебель на потолке, камера покачивается; носки, кот-призрак ворует |

## 3. Балкон, итоги, крыша (5 мин)
- [ ] Выбыл: смешной полёт с переворотом на мягкий балкон, поза (сидя / твоя из магазина), подсказка «Ты на балконе…», реакции справа снизу — всплывают над головой у всех.
- [ ] Итог этажа: окошко «⭐⭐☆», строки «Прошёл / Топ-3 / Без падений», «+N 🪙»; первый раз — «Новый этаж в коллекции!».
- [ ] После этажа все (и балкон) снова в кабине.
- [ ] 10-й этаж → крыша: пьедестал, город из кубиков, окно итогов (боты с 🤖), бонус за поездку. Потом кабина «падает»: табло «▼», тряска, «бум» — лобби.

## 4. Телефон (5 мин)
**Test → Device** → телефон в альбомной ориентации (667×375 и 812×375).
- [ ] Табло справа сверху, счёт слева сверху, меню под счётом; кнопки голосования и действия — под большим пальцем справа; левый низ свободен для стика.
- [ ] Окна магазина и коллекции целиком на экране, закрываются.

## 5. Вдвоём (5 мин)
**Test → Clients and Servers** → 2 игрока.
- [ ] Ботов теперь 2. Голоса обоих видны на кнопках; у VIP — золотая обводка и ×2.
- [ ] Второй игрок входит посреди этажа — оказывается на балконе, в кабину — на следующей остановке.
- [ ] Один выходит посреди этажа — этаж продолжается.

## 6. Магазин (5 мин)
- [ ] «Облик»: купить за монеты (DBG → +1000), надеть — шапка из деталей на голове видна второму игроку; след за спиной.
- [ ] «Капсула»: точные проценты у каждого предмета, сумма — 100%; «Открыть» → окно «Из капсулы».
- [ ] «Пропуска»: ×2 Монеты, VIP, Эмоции+, монеты, «Подвал сейчас!» (в кабине: отсчёт продлевается, объявление «Х вызвал Подвал!», следующий этаж — Подвал; второй раз за поездку — отказ).

## 7. Отладка
`workspace:SetAttribute("DebugCommand", "state")` в Command Bar (Server) → `[Debug] ride 1 phase=cabin stop=2/10 …`. Остальное: `floor <id>`, `next`, `boss`, `basement`, `bots <n>`, `speed <x>`, `auto`, `coins <n>`, `reset`, `selftest`.
